# Tutorial outlines

One outline per tutorial on the [Swarm and A2A tutorials map](https://github.com/seanrobertwright/Quay-2/issues/2),
gathered from the `prototype/outline-<slug>` branches each ticket was settled on.

Each outline is the handoff for writing its tutorial, read together with the `## Resolution`
comment on its ticket and any amendment after it. Where an outline and its ticket disagree, the
ticket wins. Slugs follow the table in [Prototype: Tutorial page template](https://github.com/seanrobertwright/Quay-2/issues/10).
