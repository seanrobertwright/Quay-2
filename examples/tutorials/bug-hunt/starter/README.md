# Cart pricing

A shopping-cart pricing library in whole cents, with a command-line tool that prints a cart's
receipt. Users have reported three things that go wrong, listed in `BUG-REPORT.md`; `AGENTS.md`
has the rules and commands for working on it.

```text
npm run receipt -- carts/three-mugs.json
```

It needs Node 24 or later, which runs TypeScript as it is.
