# AGENTS.md

**Goal:** this package is finished. It is here so agents have something real to read and
talk about.

## Commands

- `npm run greet -- Ada fr` runs the CLI, which prints `Bonjour, Ada!`.
- `npm test` runs the tests once.
- `npm run typecheck` type-checks the project.

## House rules

- This tutorial is about agents messaging each other. Don't change any file unless the user
  asks you to.
- Use npm, never yarn or pnpm. Add no dependencies.
- Write TypeScript that Node can run as it is: no `enum`, no `namespace`, no parameter
  properties.
