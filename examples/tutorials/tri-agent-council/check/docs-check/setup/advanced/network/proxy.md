# Proxy

## HTTPS proxy settings (v2+)

Set `HARBOR_PROXY` to your proxy's address, for example <https://proxy.example.com:8080>.

To remove Harbor, follow [Uninstall](../../uninstall.md#steps).

If requests time out, see [Troubleshooting](#troubleshooting) below.

## Trouble-shooting

Check the proxy with [the install guide](../../install.md#install-harbor) and [the README](../../../README.md).
