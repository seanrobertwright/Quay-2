# Command-line reference

## Commands

### build

Builds the site. It exits as [Exit codes](#exit-codes) says.

### serve

Serves the site and rebuilds it on every save. A link in an example isn't checked:

```md
[home](../missing.md)
```

## Exit codes

Inkwell exits 0 when the build succeeds. See [exit code 1](#exit-code) for a failed build.
