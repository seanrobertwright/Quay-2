# Configuration

Inkwell reads `inkwell.json` from the folder you build.

## Options & flags

| Option | Does |
| --- | --- |
| `out` | The folder the site is written to. |
| `watch` | Rebuild on every save. |

## Environment variables

`INKWELL_OUT` overrides `out`. See [Options & flags](#options--flags).
