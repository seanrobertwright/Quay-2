# Getting started

Install Inkwell, then build your first site.

## Install

Run this in a terminal:

```sh
npm install --global inkwell
```

## Your first site

Put your notes in a folder, then run [the build command](../reference/cli.md#build).

Choose where the site goes with an [environment variable](config.md#enviroment-variables).

Back to [the start](../index.md).
