The Agents module holds five things today: Waiting on You, Swarm presets, Mission Control, Session History and the Action Log. Today each one is its own drawer or modal. Here are four ways to lay them out across the panel, the companion and a stage tab. The card below walks you through it.

        My recommendation

        B · Lists left, detail right

        • It follows the rule the companion already set: things that belong to one terminal (its permission request, its tool calls, its messages to other agents) sit beside that terminal. Things that span terminals (who is waiting, which agents exist, swarms, past sessions) are lists in the panel.
        • Nothing covers the terminal. Today the permission request is a modal and four of the five are drawers over the screen; D keeps the modal and puts the rest in a tab that hides the terminal.
        • Panel order is how often the loop needs each one: Waiting on You (grows to 5 rows, then scrolls), Agents in this project with each one's latest reply, saved Swarms (built-in presets and the builder open in a stage tab), and Session History filling the rest with search.
        • The Action Log and the message trail merge into one Activity view in the companion, for the selected terminal. A message strip at its foot sends a task to that agent, which replaces Mission Control's dispatch form. Broadcast moves to the palette.

        The cost: the companion gets a second view (Pull request or Activity), so one more switch to learn. In my own run of the job, following the outline, B took 7 clicks, D 8 (one of them only to get back to the terminal), and A and C 10 each, because every step there starts by opening a section or tab.
