# Shell redesign prototypes

Throwaway prototypes for the Quay shell redesign map. This branch is a
record only and is never merged. Each page is a standalone HTML fragment
with example data; nothing is wired to Quay.

- `quay-shell-prototypes.html`: four ways the rail could collapse, and six
  icon candidates for the Praxis Builder. Chosen: the module bar with a
  panel, and the Canvas Handles icon.
- `quay-window-concepts.html`: four arrangements of terminal and pull
  request in one window. Chosen: the companion that follows the selected
  terminal.
- `quay-pie-menu.html`: the two-ring pie menu as a transparent neon
  wireframe in six palettes. Chosen: all six as a setting, spectrum as the
  default.
- `quay-companion-pr-view.html`: four ways to fit GitHub's new pull
  request view into the companion, with a live click and pointer-travel
  counter. Chosen: readiness first, where the readiness cells are the
  navigation.
- `quay-companion-wide.html`: four ways for the companion to go wide for
  a large diff. Chosen: the diff lens, which slides the files over the
  terminal while the companion keeps the readiness card and merge.
- `quay-command-surfaces.html`: interactive prototype showing where every
  command lives across the module bar, 5 module panels, pane header,
  companion, 2-ring pie menu, and command palette.
- `quay-tool-placement.html`: four placements (module panel, companion,
  stage tab, full-window) for Topos, Praxis Builder, and Machina Factory.
  Chosen: Topos in companion (with Wide), Praxis Builder as a stage tab,
  Machina Factory in the Workflows panel.
- `quay-stage-and-status.html`: four candidates for what becomes of the
  stage header and status strip (Pure Canvas, Stage Tabs Only, Micro
  Statusline Only, Dual Micro Bars) across Single, Split, and Grid layouts.
- `quay-pie-second-ring.html`: a guided, timed mouse test of four ways to
  reach the pie menu's second ring (distance, turn, pause, turn or pause).
  Chosen: distance, with the outer slices locked to the nearest action
  that has sub-actions.
- `praxis-builder-canvas-handles.svg`: the approved Praxis Builder icon.
- `quay-pie-contexts.html`: three schemes for what the pie holds over a
  terminal, the companion pull request, the module bar or a panel row, and
  an empty stage, with a grid of which strokes stay fixed. Chosen: fixed
  axes with family diagonals.
- `quay-module-bar-badges.html`: four ways the module bar shows terminal
  status while the Projects panel is closed, with a scripted event feed and
  a click counter. Chosen: a dot per terminal under the Projects icon.
- `quay-agents-panel.html`: four layouts for the Agents module (one
  accordion, lists left with detail in the companion, tabs in the panel,
  an Agents stage tab), with a guided six-step job, a click counter, and a
  table of where each part opens. Chosen: B, lists left with a terminal's
  own activity in a companion Activity view.
- `quay-workflows-panel.html`: four layouts for the Workflows module (by
  engine with a Run stage tab, by state with detail in the companion, engine
  tabs in the panel, a Workflows stage tab), with a guided six-step job over
  Archon runs, Factory work orders and Praxis graphs, a click counter, and a
  table of where each part opens. Chosen: B, by state, with a run's detail
  in a companion Run view.
- `quay-shell-preferences.html`: four homes for the shell's own settings
  (pie palette, label outline, pie delay, Merge undo window, companion's
  first view): a Project panel group, a Settings stage tab, palette only, or
  in place on the pie and companion, with a guided five-step job, a click
  counter, and a table of where each one lives. Chosen: A, a Quay group
  in the Project panel.
- `quay-shell-look.html`: four looks for the rest of the shell beside the
  neon pie menu (today's look, neon accents on live state only, a full
  wireframe, and islands, a new calm style), with the pie opening over the
  terminal in each, a pie palette and glow switch, live contrast readouts,
  a part-by-part table, and a guided six-step walkthrough. Chosen: B, neon
  accents, following the pie palette, with soft glow.
- `quay-ticket-pipeline.html`: four answers to whether the Projects module
  shows each ticket's way from ticket to terminal to pull request to merged
  (no pipeline, a lane on each terminal row, a strip over the stage, and a
  board stage tab), with a guided four-step job, a click counter, and a
  table of what each one shows and where.
