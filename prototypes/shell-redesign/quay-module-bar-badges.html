How to use this page

  1. Pick a variant below.
  2. Press Next event to play what happens while you read a pull request: an agent stops to ask you something, another crashes, you answer one.
  3. After each event, click whatever on the module bar would get you to that terminal. The counter shows clicks used.
  4. Try all four, then answer the questions back in the terminal.
