# Topos Logo Concepts

20 logo concepts for **Topos**, the native visual Git Cockpit in Quay 2.
Each concept includes a horizontal lockup (`NN-name.svg`) and an icon-only mark (`icons/NN-name.svg`).

To preview all 20 side by side with responsive 64px, 32px, and 16px scaling, open [`index.html`](index.html) in your browser.
