# Praxis logo concepts

Logo concepts for Praxis, the workflow engine. Each concept has a horizontal
lockup (`NN-name.svg`, icon plus wordmark) and an icon-only mark
(`icons/NN-name.svg`). Open `index.html` to compare them side by side.

The wordmarks use system fonts. To ship one, convert its text to outlines
in a vector editor so it renders the same everywhere.

## 01. Deliverable Gate

A classical gateway with a gold deliverable passing between the pillars. Work
moves only when the gate opens.

- Lockup: [`01-gate.svg`](01-gate.svg)
- Icon: [`icons/01-gate.svg`](icons/01-gate.svg)
